# Alizé Pilote

Application mobile de chiffrage, facturation et gestion d'équipe pour les artisans du BTP à La Réunion.

## Accès à l'app

**Code d'accès** :
Code à 6 chiffres saisi au pavé de l'Écran de verrouillage. Terme générique pour le Code patron et le Code salarié.
_À éviter_ : PIN (sauf dans le code), mot de passe

**Code patron** :
Code d'accès du responsable de l'entreprise ; il ouvre toute l'app.
_À éviter_ : code maître, code propriétaire, ownerCode

**Code salarié** :
Code d'accès propre à un seul salarié ; il n'ouvre que son pointage et ses notes de frais. Deux salariés n'ont jamais le même Code salarié.
_À éviter_ : code équipe, code commun

**Écran de verrouillage** :
Écran qui demande un Code d'accès avant d'ouvrir l'app. Il protège l'usage de l'app, pas les données enregistrées sur l'appareil.
_À éviter_ : écran de connexion, écran de code

**Verrouillage automatique** :
Retour à l'Écran de verrouillage quand l'app est restée en arrière-plan plus longtemps que le délai choisi par le patron.
_À éviter_ : mise en veille, déconnexion

**Code à renouveler** :
État d'un salarié dont l'ancien Code salarié a été désactivé ; il ne peut plus ouvrir l'app tant que le patron ne lui a pas généré un nouveau code.
